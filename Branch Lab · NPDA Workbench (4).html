How to read the rules

  • Each line: state, input, top -> next, push. e means empty (ε).
  • Push text puts its first letter on top. e pushes nothing, so it pops.
  • Clone: every choice becomes a new branch and all run together.
  • Backtrack: follow one branch; if it dies, return to the last choice.
  • Choose ✍ Write it manually (top of the machine list) to type your own machine.
  • Accepted if any branch reads all input and ends in a final state (or empty stack).
